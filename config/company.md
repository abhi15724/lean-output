# User / project defaults

Edit this file only when these defaults change. Keep project-specific facts in the project, not here.

## Defaults
- Region: India; use INR and IST when relevant.
- Web: mobile-first, accessible, lightweight; Vercel unless the user specifies another target.
- Static sites: HTML/CSS/JS unless accounts, APIs, or data make a framework useful.
- AI/ML: Python; environment variables for secrets; include one smoke/evaluation check.
- Blogger: preserve Blogger XML structure and avoid unnecessary external dependencies.
- Language: match the user's language; English by default.
